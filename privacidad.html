Política de privacidad de PolyGloo Publisher

Última actualización: 20 de noviembre de 2026.

Qué es

PolyGloo Publisher es una herramienta interna del canal PolyGloo. Solo la usa el propio canal para subir y programar sus vídeos en sus propias cuentas de YouTube, TikTok, Instagram y Facebook. No está abierta al público.

Qué datos usa

Únicamente los permisos que el propio canal concede sobre sus cuentas (por ejemplo, subir vídeos a su canal de YouTube). No pide, recoge ni guarda datos de otras personas.

Cómo se guardan

Las claves de acceso se guardan cifradas y nunca se comparten, se venden ni se usan para publicidad. El uso de datos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

Cómo retirar el permiso

El acceso se puede retirar en cualquier momento desde la página de permisos de tu cuenta de Google.

Contacto

Mensaje directo a @its_polygloo en Instagram.
